# Матрица совместимости

Метки статуса: **VERIFIED** (проверено на фактически закреплённом runtime),
**NEEDS TESTING** (задокументировано, но ещё не выполнено на целевом хосте),
**BLOCKED**. Ничего здесь не заявляется работающим без своей метки.

## Политика закрепления версий

* **vLLM** — закреплён по дайджесту образа (`@sha256:`), принудительно запускаемыми
  скриптами.
* **LMCache** — закреплён в `requirements-lmcache.txt`; таблица выше называет
  ЕДИНСТВЕННЫЙ проверенный кортеж. Обновление требует повторного прогона
  `scripts/test-recovery.sh` (критерий успеха — дисковое восстановление, а не
  «импортируется»).
* При несовпадении ABI запускайте `lmcache server` из production-образа
  (docs/troubleshooting.md).

## Почему LMCache

| Кандидат | Вердикт |
|---|---|
| `nixl_store_dynamic` (LMCache L2) | выбран: persist/recover + ограниченная ёмкость + эвикция L2 |
| `nixl_store` | отклонён: предварительно выделенный реестр, восстановление после рестарта недокументировано |
| In-process `LMCacheConnectorV1` | отклонён: кэш умирает вместе с процессом vLLM |
| Только встроенный prefix cache vLLM | недостаточно: умирает при рестарте — эта проблема и решается |
| Кастомный коннектор-адаптер | не требуется — в закреплённом vLLM есть MP-коннектор |
